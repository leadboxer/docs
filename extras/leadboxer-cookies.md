# LeadBoxer cookies

The leadBoxer tracking script aka 'lead pixel' executes a script to set **first-party** cookies.

Here is an overview of the first-party cookies we set and the detail about these cookies;

These cookies are set on your own domain (first-party). They contain anonymous IDs and are used only to recognize returning visitors and to link page views to the same session. LeadBoxer does not set third-party cookies.
