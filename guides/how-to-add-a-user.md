# How to add a user

## How to add a user to your account

{% hint style="info" %}
Note: you need to have admin permissions to be able to add or modify users
{% endhint %}

1. Login to your account&#x20;
2. In your profile menu (top right) select **Users**

<figure><img src="../.gitbook/assets/LeadBoxer_App (3) (2).png" alt=""><figcaption></figcaption></figure>

3. On the Users page click **Add A User**
4. Enter the email address, first name and last name of your colleague
5. Select the dataset(s) the user should have access to (and the client, if you work with [Clients](../fundamentals/elements/clients-agents.md))

<div align="left">

<figure><img src="../.gitbook/assets/LeadBoxer_App (12).png" alt=""><figcaption></figcaption></figure>

</div>

6. Once saved, an email will be sent to the new user asking them to create a password and they will then have access to the account.

### Managing users

From the menu next to each user on the Users page you can:

* **Resend Invite** if the user didn't receive or lost the invitation email
* **Edit User Name** and **Edit User Role** (see [Roles & Permissions](../fundamentals/elements/roles-and-permissions.md))
* Give access to more datasets, or **Delete Access** to a dataset
* **Delete User**

You can also add a user from a dataset: go to **Datasets**, open the dataset's menu and choose **Add New User** or **Give Access To Existing Users**.
